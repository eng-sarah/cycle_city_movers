Cycle City Movers — Cycle Sort puzzle (browser game)

Run:
1) Unzip
2) Open index.html in any modern browser (Edge/Chrome/Firefox)

How to play:
- Click any apartment to pick up its crate.
- The crate's home apartment glows green.
- Click the glowing home to write the crate there (counts as 1 write).
- You will pick up the displaced crate and continue following the cycle.
- When your carried crate is already in its home, the cycle ends.
- Sort the city with as few writes as possible.

Notes:
- Optimal writes shown = N - number_of_cycles in the permutation.
- Strict mode enforces cycle-sort style placements.
